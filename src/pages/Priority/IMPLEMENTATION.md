## 상호작용
- 지역/취약도/처리 상태/주소·접수번호 검색, 조건 초기화, URL 유지
- 체크박스 또는 접수번호/행 선택 → 해당 상세와 선정 근거 표시
- 담당자 선정 메모 입력, 대상 지정 확인/취소 → 지정 완료 → 확인
- 지정 후 배정 일정은 별도 현장점검 관리에서 처리한다는 안내
- 순서 편집 진입 → 지정·미배정 대상만 이동 가능
- 정렬 핸들 드래그 또는 키보드 위/아래 → 순서 변경
- 정렬 핸들 클릭 → 보완 순서 모달(위/아래 버튼) → 취소/저장
- 순서 저장 완료, 모달 Escape 및 배경 클릭 닫기, 초점 가두기
- 새로고침/직접 URL 접근 지원. 지정/메모/순서는 flout-priority-mock-v1 localStorage에 저장
- dataset=empty는 빈 Mock 자료를 검수하기 위한 URL fixture이며 별도 제품 버튼을 추가하지 않았습니다.

## Figma 원본에서 확인되지 않거나 불일치한 부분
1. 기본 선택은 000006·주소 ○○길 60인데 상세 제목은 000001·김○○로 적혀 있습니다. 실제 선택 신청으로 일치시켰습니다.
2. 10건인데 5개 페이지 버튼이 있습니다. 제공된 10건만 사용하며 2~5·이전/다음은 데이터가 없어 비활성화했습니다. API/추가 Mock 자료가 생기면 실제 총건수에 연결해야 합니다.
3. 지역/처리 상태 드롭다운 옵션, 일부 주민 이름·주소·담당 배정 여부는 Figma에 세부 데이터가 없습니다. Mock 데이터/선택값을 코드에 분리했습니다. 000052는 배정 완료 Mock으로 두어 와이어프레임의 '배정 완료 신청은 순서 변경 제외' 규칙을 확인합니다.
4. 최종 프레임에는 링크/프로토타입 연결이 없습니다. 버튼 이름과 와이어프레임 설명을 기준으로 흐름을 연결했습니다.
5. 기존 Sidebar의 선택 아이콘 색·Header 담당자 및 날짜는 현재 프로젝트 그대로 재사용했습니다. 범위 밖 공통 화면은 수정하지 않았습니다.
6. 최종 모달은 Inter, 본문은 Pretendard로 반환되어 해당 family를 각각 지정했습니다. 환경에 해당 글꼴이 없으면 fallback이 표시됩니다.
